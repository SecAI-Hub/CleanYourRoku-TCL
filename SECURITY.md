# Security

Report potential vulnerabilities privately through this fork's GitHub Security tab.
Do not post credentials, device identifiers, account/profile screenshots, or viewing
history in public issues. Describe the source revision, affected control, and impact
without including private TV/network data.

The channel contains only bundled resources and configured native app launches.
The build and optional read-only icon fetcher have explicit boundaries documented in
`docs/privacy-security.md`. Local package/source checks do not certify Roku firmware
or streaming services. Keep the local developer installer on a trusted network.

Use only this repository's reviewed source and validate the package hashes. A developer
password belongs in the user's browser; no computer helper needs it. Retain a previous
ZIP/source revision before replacement for rollback. Build artifacts and personal logos
are git-ignored and must not be committed.
